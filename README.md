# Banco UdeA - Backend API

API RESTful desarrollada para la gestión del sistema transaccional **Banco UdeA**, correspondiente al Laboratorio N° 1 de Arquitectura del Software
Universidad de Antioquia.

## Tecnologías Utilizadas

* **Java 21**
* **Spring Boot 3.x**
* **Spring Data JPA / Hibernate**
* **MySQL** (Motor de base de datos relacional)
* **Maven** (Gestor de dependencias)

## Requisitos Previos

* **JDK 21** instalado y configurado.
* **MySQL Server** corriendo en el puerto `3306`.
* Base de datos creada en MySQL:
  ```sql
